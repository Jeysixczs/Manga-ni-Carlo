# Kitsunescan UI redesign

## React app updates
- Redesigned global header with responsive burger navigation and theme toggle.
- Added a landing hero section to the Explore page.
- Added responsive, minimalist visual styling for navigation, search, cards, grids, and spacing.
- Existing routes, MangaDex fetching, and reader behavior are retained.

## Separate HTML screen mockups
Open `client/screens/home.html`, `client/screens/details.html`, and `client/screens/reader.html` directly in a browser. They are standalone UI mockups with shared `screens.css`; their manga content is sample placeholder content. The React app remains the functional version connected to your existing API.

## Run the app
From `client/`: `npm install` then `npm run dev`.
